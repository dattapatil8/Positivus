# Positivus 🚀

### Demo Link 🔗
https://positivus-xi-beryl.vercel.app/

A modern and responsive digital marketing agency landing page built using React.js and Tailwind CSS.

This project was built to strengthen my frontend development skills by practicing reusable React components, responsive layouts, clean UI structuring, and real-world landing page design.

The design is inspired by the Positivus UI concept, and the complete frontend was developed while learning and exploring modern React development practices.

---

## 📌 Features

- Responsive Navbar
- Hero Section
- Services Section
- Case Studies
- Working Process Accordion
- Reusable Components
- Modern UI Design
- Fully Responsive Layout
- Clean Component Structure

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone <your-repository-link>
```

Move into the project directory:

```bash
cd Positivus
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
